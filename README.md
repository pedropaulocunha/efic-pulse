# Pulse

Plataforma de sala da Efic Soluções. Regras do projeto em `CLAUDE.md`; briefings das fatias em `docs/`.

- `npm run dev` — roda em http://localhost:3000
- `supabase/migrations/` — SQL para colar no SQL Editor do Supabase, na ordem dos números
- `supabase/tests/isolamento.sql` — teste das políticas de acesso
- `supabase/templates/` — textos dos e-mails de autenticação
